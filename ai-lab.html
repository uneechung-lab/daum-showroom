변경된 영향 범위 선별부터 테스트 시나리오 자동 실행, 결함 원인 분석 및 화면 매뉴얼 작성까지 단번에 해결합니다. 자세히

Impact Tracer 영향선별

+

Loop Verification

등록-조회-수정-삭제 전 주기를 묶어 데이터 저장의 실제 정합성까지 깊게 검증합니다.

+

Safe Rollback

AI 수정안 승인 전에는 코드가 변경되지 않으며, 문제 시 언제든 이전 상태로 롤백할 수 있습니다.

Major Research Fields

주요 리서치 분야

SI 현장의 생산성과 품질을 혁신하는 3가지 핵심 연구 분야입니다.

AI 기반 개발 환경 (AI IDE)

AI 코딩 도구를 활용한 차세대 개발 환경(AI IDE) 구축을 진행하고 있습니다. 개발자의 생산성을 극대화하고 반복적인 개발 작업을 자동화합니다.

  • AI 기반 코드 생성
  • 코드 리뷰 자동화
  • 테스트 케이스 자동 생성
  • 개발 문서 자동 생성
  • 코드 품질 분석 자동화

바이브 코딩 (Vibe Coding)

AI와 협업하는 새로운 개발 방식인 바이브 코딩을 연구하고 있습니다. 개발자가 요구사항과 설계 방향을 제시하면 AI가 코드 작성과 테스트를 수행합니다.

  • 요구사항 기반 코드 자동 생성
  • UI 자동 생성
  • 테스트 자동 생성
  • 코드 리팩토링 자동화
  • 실시간 성능 모니터링

솔루션 고도화

회사의 기존 솔루션을 AI 기반 서비스로 고도화하고 있습니다. 지능형 기능을 추가하여 사용자 경험을 획기적으로 개선합니다.

  • AI 기반 데이터 분석 기능
  • 자동 보고서 생성
  • 업무 자동화 기능
  • 지능형 검색 기능
  • AI 챗봇 서비스
AI SI Process

AI 기반 SI 수행 프로세스

AI 도구와 자동화 기술을 결합하여
기존보다 빠르고 품질 높은 시스템을 구축하는 4단계 방법론입니다.

STEP 01
1

AI 요구분석

AI가 요구사항 문서를 분석하여 기능 목록과 데이터 모델을 자동으로 도출합니다.

STEP 02
2

바이브 코딩

개발자가 방향을 제시하면 AI가 코드를 작성·리뷰하며 반복 개발 사이클을 가속합니다.

STEP 03
3

자동화 검증

AI가 테스트 케이스를 자동 생성·실행하여 품질을 지속적으로 검증합니다.

STEP 04
4

지속 고도화

운영 데이터를 AI로 분석하여 시스템 성능과 사용자 경험을 지속적으로 개선합니다.

원스톱 AI 품질관리 도구

에이큐엠(AI-QM)

테스트 수행부터 결함 등록·원인 진단·수정 조치, 화면 매뉴얼 작성까지 자동화하는 사내 AI 품질관리 도구입니다. 단발성 테스트를 넘어 데이터 정합성과 결함 해결까지 원스톱으로 검증합니다.

결함 자동 등록 원인 분석·해결 매뉴얼 자동 생성 E2E 순환 검증
  • 서버 처리 결과 및 실제 화면(E2E) 조작 병행 자동 점검
  • 코드 변경 시 영향 화면 자동 선별 및 시나리오 자가 보완
  • 등록·조회·수정·삭제(CRUD) 순환 검증으로 데이터 무결성 보장
  • 실패 원인 AI 진단, 결함 자동 등록 및 수정안 제시 (승인 후 재점검)
  • 화면 사용 설명서(목적·처리순서·흐름도) 자동 작성 및 시스템 연동

AI 리서치의 핵심 산출물
